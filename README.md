# Coffee Shop Sales Dashboard

## Project Overview
Excel dashboard project analyzing coffee shop transaction data to identify revenue trends, top-performing products, store performance, and customer traffic patterns.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Excel Formulas
- Data cleaning

## Key KPIs
- Total Revenue: $698,812.33
- Total Transactions: 149,116
- Average Revenue per Transaction: $4.69

## Key Insights
- Hell's Kitchen generated the highest revenue at $236,511.17.
- Barista Espresso was the highest-revenue product type.
- Monday was the busiest day of the week.
- 10 AM was the busiest hour of the day.
- Revenue showed an overall upward trend from January through June.
